# 損切り幅の下限を 1.0 × ATR(14, 日足) にする（#1122）

> 本仕様書は実装着手前に作成する（着手時の調査・設計と、実装後の試験・自己変異の結果を同じ文書に残す）。

## 起点となる計画書（トレーサビリティ）

- 機能要求（FR）: FR-10（ATR 連動・銘柄別損切りラインの既定値）・FR-04（判断の材料）・FR-11（監査）・FR-15（Stage 0）
- ユースケース: UC-01（取引サイクル）
- 計画 ADR: ADR-0049 決定1〜4（下限 ＝ 1.0 × ATR(14)・得られなければ参照価格の 2%・割った幅は広げる・1 注文上限は緩めない・Stage 0 も同じ値）・
  ADR-0048 決定3（日足を判断へ流す条件）・ADR-0003・ADR-0023 決定5
- 実装 ADR: [IADR-0486](../adr/IADR-0486_stop-width-floor-atr14-flag-and-floor-marker-on-order-intent.md)（本件）。改める: IADR-0465 決定1・2・4・5、IADR-0472 追記 2 の残余
- issue: #1122（前提 #1117・#1118 は済み。#1120・#1136 は develop に入っている）

## オーナー裁定（2026-10-03）

**案 A、予約の経路も閉じる。**

- 問題: 発注執行の遡及（`SoftwareStopFloorRetrofitter` / `StopWidthFloorRetrofitPolicy.WasSizedBelowFloor`。#1136・IADR-0472）は「ラインを引いた価格（`PlannedPrice`）から 2% 未満のライン」だけで
  下限の導入前の行を見分ける。参照価格の 2% より狭い ATR の下限で建てた行を導入前の行と取り違えて広げる（ADR-0049 決定1 に反する）。
- 案 A: `OrderIntent` に末尾の既定 null の項目（下限の出所の印）を足し、取引判断が新規建てで立て、リスク管理はそのまま運び、発注執行が `ExecutionRecord` / `ExecutedOrderRow`
  （マイグレーション）と**予約の行**（`OrderReservationReconciler.BuildRecord` がブローカーの注文から組み直しても印を保つ。2 本目のマイグレーション）に残す。
  遡及は印が「下限を掛けて建てた」を示す行を外す（null の行は従来の判定）。契約の変更を記録する。IADR-0465 の「`OrderIntent` に載せない」を新しい IADR で改め、IADR-0465・IADR-0472 に日付つき追記を置く。

## 設計（IADR-0486）

1. **設定**: `StopWidthFloor:Atr14:Enabled`（既定 false・`bool.TryParse`＝既存の `DecisionVolume:Enabled` と同じ読み）。日足の口は DI キー `daily-bars-shared` の 1 つの singleton を共有し、
   どちらかが有効で `OrderExecution:BaseUrl` が絶対 URL のときだけ Cached。出来高の口は出来高が無効なら NoOp、`IStopWidthFloorSource` は ATR が有効で共有の口が `IsEnabled` のときだけ Atr14。
2. **判断**: 下限を判断ごとにプロンプトの前（出来高と同じ位置）に 1 回だけ読む（`StopWidthFloorContext`）。無効なら読まない。適用は `Resolve(stopFloor?.Supplied, アンカー後の参照価格)`。
   新規建ての発注意図に `StopFloorSource ＝ StopWidth.FloorSource`。
3. **ATR**: `AverageTrueRange.Compute`（最後の 15 本・最後の足 ＝ 前営業日・壊れた足は null・14 本の TR の単純平均）→ `StopWidthFloorPolicy.FromAtr`（1.0 × ATR・出所 Atr14・ATR の値）。
4. **プロンプト**: 有効なときだけリスク制約節に下限の行（得られた／未提供）。観測ログに `atr14`。
5. **Stage 0**: `GetFloorAsOfAsync` ＋ デコレータ `StopWidthFloorAsOfDecisionInputProvider`（監視銘柄 → 下限 → 出来高 → 入力なし）。`SignedQuantity` は `Resolve(input.StopFloor?.Supplied, 記録の参照価格)`。
6. **契約**: `OrderIntent.StopFloorSource`（`StopWidthFloorSource?`・末尾・既定 null）。リスク管理は変更なし（運ぶだけ）。
7. **発注執行**: `ExecutionRecord.StopFloorSource`・`ExecutedOrderRow.StopFloorSource`・`OrderDispatchReservation(Row).StopFloorSource`・`TryReserve(..., stopFloorSource = null)`。
   通常の発注は予約と記録の両方へ、突合は予約の印を `BuildRecord` へ。マイグレーション 2 本（列の追加だけ）。
8. **遡及**: `WasFloorAppliedAtSizing(印)` が true の行は外す（前の端・後の端の共通の `ShouldWiden`）。
