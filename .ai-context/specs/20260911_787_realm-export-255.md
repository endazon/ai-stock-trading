# 仕様書: realm export の 255 文字上限（#787）

## 起点

- 基盤の submodule pin を #780 を含む AST へ前進させた直後、基盤の integration-stack（run 34609129031）で Keycloak が
  `Value too long for column "DESCRIPTION CHARACTER VARYING(255)"`（SQLSTATE 22001）で起動失敗。#780 が写しの注記を
  `description` / realm `attributes` へ長文で入れていた（6 箇所・最長 621 文字）。

## 設計

| 対象 | 変更 |
| --- | --- |
| `infra/keycloak/realm-export.json` | client 2・role 2 の `description` と attributes `_scope` / `_sourceOfTruth` を 255 文字以内へ短縮（写しである旨と正本の所在は残す。最長 231） |
| `scripts/check-realm-export.js`（新規） | client / role / clientRole の description・realm attributes の値・name 系が 255 文字以内。`--self-test`（陽性・陰性対照・マルチバイト） |
| `.github/workflows/ci.yml` | static-checks に self-test ＋ 実行を接続。`scripts/README.md` に登録 |

基盤の `check-realm-constraints.js`（MSP#18）と同じ規律。基盤側は写し突合器（MSP#1412）へ 255 文字検査を足す（別 issue）。

## 受け入れ基準

- [x] `node scripts/check-realm-export.js` が実データで OK（7 項目）・self-test 6 件緑
- [x] 短縮前の export に戻すと exit 1（6 件を名指し）
- [ ] 基盤の submodule pin 前進後の integration-stack で Keycloak が起動する
