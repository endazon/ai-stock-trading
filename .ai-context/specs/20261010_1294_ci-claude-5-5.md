# 仕様書: CI のレビュー・実装用 Claude モデルを 5.5 系へ揃える（#1294）

## 起点となる計画書（トレーサビリティ）

- 要求: 無採番の `NFR`（CI の運用性。メタ作業）。製品の FR には当たらない。
- 利用者裁定（2026-10-10・planning#783）: Claude のモデル割当をすべて 5.5 系へ切り替える。CI のレビュー・実装用の設定も同じ 5.5 系へ揃える。

## 変更

| 現行 | 移行先 |
| --- | --- |
| `claude-sonnet-5`（既定） | `claude-sonnet-5-5` |
| `claude-opus-5` | `claude-opus-5-5` |
| `claude-haiku-4-5-20251001` | `claude-haiku-5-5` |
| `claude-fable-5`（`@claude fable` の選択肢） | `claude-fable-5-1` |

- モデル ID は日付接尾辞なしの厳密な ID とする。
- Fable は選択肢として残す（明示のメンション時だけ起動する。既定は変えない）。
- 対象箇所: レビュー `claude-code-review.yml` :17・:191・:201-205・:235、実装 `claude-coding.yml` :21・:88・:104-108・:126。

## 5.5 系が拒否する指定の有無

- 5.5 系は thinking の無効化・`budget_tokens`・非既定の temperature を 400 で拒否する（planning#783）。
- 両ワークフローの `claude_args` は `--model` / `--allowedTools` / `--append-system-prompt` だけで、`--max-thinking-tokens` 等は渡していない。是正は不要である。

## 変えないもの

- 起動条件（`on:` / `if:`）・ジョブ名（必須 check 名）・`--allowedTools`・プロンプト。
- ランタイム（取引判断の割当表・単価表）は別 issue の対象であり、本件では触らない。`.github/workflows/helm.yml`・`scripts/nightly-ledger-summary.pg.test.sh` 等に現れるモデル名はランタイムの単価・台帳の記述なので除外した。

## 母集合（規則 9）

- `git grep -nE "claude-(sonnet|opus|haiku|fable)" origin/develop -- .github AI_SETUP.md AGENTS.md CLAUDE.md .claude docs/ai-*.md scripts` で引いた。
- CI のモデル選択を持つのは上の 2 本だけで、`AI_SETUP.md`・`docs/ai-workflow.md`・`docs/ai-orchestration.md`・`ai-roster.json`・`scripts/check-ai-workflow-config.js` にモデル名の記述は無い。

## 規則 10・11

- 規則 10: 変更後に旧 ID（`claude-sonnet-5` 等の語境界一致）で両ワークフローを引き直し、0 件であることを確かめた。
- 規則 11: 窓（時間差）を扱わないので該当しない。

## 検証

- `STRICT_AI_WORKFLOW_CONFIG=1 node scripts/check-ai-workflow-config.js`
- `actionlint .github/workflows/claude-code-review.yml .github/workflows/claude-coding.yml`
- `node scripts/check-trace-blocks.js` / `node scripts/check-cross-repo-refs.js` / `node scripts/check-commit-messages.js`
