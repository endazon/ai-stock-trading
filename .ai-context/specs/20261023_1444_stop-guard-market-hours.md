# 仕様書: 閉場中は保護逆指値ガードと S1 が新しい注文を送らない（#1444）

> 本仕様書は実装着手前に作成した（着手 2026-10-23。AST `origin/develop` `61f12225`）。判断の記録は IADR-0574。

## 起点（トレーサビリティ）

- 起点: #1444（親 #1423 の M-1。監査は develop `40de5a61`・読み取りのみ）。関連 #1214（GTC の可否・日次の置き直し）。起点 ID は `NFR`（親の監査の分類に合わせる）。統制は FR-10（逆指値なしの建玉を持たない）。
- 計画: ADR-0040 決定 4 の表の 2 行目（「有効期限が当日限りであること（GTC 不可）」。実弾で GTC の逆指値が翌営業日も残るかは未確認。残らないなら日次で置き直す経路が要る。**経路は定めない**）。
  業務フロー 02「逆指値の未受理・失効を検知 → 再発注、不可なら成行で手仕舞い」は**時間帯を定めていない**。
- 採番: develop の IADR の最大は 0573、開いている PR は #1159（CHANGELOG・IADR なし）。本件は IADR-0574（push 直前に再確認）。試験 ID は develop の最大 T-10-2994 の次から T-10-2995〜T-10-3001。

## 原因（コードで確認）

1. 保護レグは有効期限を載せない（`MoomooBrokerAdapter` が DAY を載せるのは指値の決済だけ）＝当日限り。引けで失効する。
2. `ProtectiveStopGuardService` は時間帯を見ずに 30 秒ごとに巡回する。`ProtectiveStopGuard.EvaluateAsync` は失効（Cancelled／Rejected／Expired）・建玉残ありで
   `ReplaceOrCloseAsync` へ進み、逆指値を張り直し、拒否なら成行で手仕舞う。**閉場中もそのまま送る。** 場外の成行は翌寄りで約定し、損切りラインに達していない建玉を寄り値で手仕舞う。
3. S1 の到達済み行は、ガードの巡回（`TryCloseAsync`）が成行を撃ち直す。市場監視は閉場中に到達を出さない（IADR-0380 決定 2）が、**ガード経由の撃ち直し**と**引け際の到達の配送の遅れ**は閉場中に成行を送る。
4. 市場時間の参照が発注執行の巡回に無い（`grep -rn "MarketHours\|IsOpen\|MarketSession"` が `GuardProtectiveStops/`・`ExecuteSoftwareStops/`・`Hosted/` に該当なし。発注執行の利用は判断由来の決済の取消の `ZoneOf` だけ）。

## 母集合（規則 9: 発注・成行を送る呼び出しで走査）

`grep -rn "PlaceMarketOrderAsync\|PlaceStopOrderAsync\|\.PlaceOrderAsync" backend/Services/OrderExecutionService --include=*.cs`（試験・宣言・アダプタの内側を除く）。

| 呼び出し | 起動のされ方 | 本件の扱い |
| --- | --- | --- |
| `ProtectiveStopGuard.ReplaceOrCloseAsync` の逆指値の張り直し | 常駐の巡回（`ProtectiveStopGuardService`・30 秒） | **決定 2**（閉場中は送らない） |
| `ProtectiveStopGuard.ReplaceOrCloseAsync` の成行の手仕舞い | 同上 | **決定 2** |
| `SoftwareStopExecutor.TryCloseCoreAsync` の成行 | 巡回（到達済み行の撃ち直し）と `StopLossTriggeredHandler`（到達の購読） | **決定 3**（両方の入口が通る 1 点で止める） |
| `OrderExecutionAppService` のエントリー・同時の保護逆指値・未受理時の成行（`:436-439`・`:1029`・`:1570`） | 承認（`OrderApproved`）の受信 | **対象外**。承認は場中の判断から出て、閉場前の締め切り（IADR-0561）がある。巡回ではない（親の指摘の範囲外）。残余 3 |
| `Hosted/` の他の常駐（約定追跡・突合・建玉観測・稼働 probe・保持） | — | 注文を送らない（grep に該当なし）。取消は送るものがある（判断由来の決済の取消）が、新しい注文ではない |

ガードの巡回の中で注文以外にブローカーへ出るもの: 残存逆指値の取消（建玉消滅時。反対建玉の防止）・未約定エントリーの残りの取消（S1）。**取消は閉場中も止めない**（取り消さないと建玉なき逆指値が翌寄りで発火し得る）。

文書（規則 9: `再発注`・`不可なら成行`・`保護逆指値ガード` で走査）:

- `docs/functional/FR-10_risk-controls.md` の場面の表（失効 → 再発注）→ 閉場中の行を足す。
- `docs/tests/FR-10_risk-controls-tests.md` → 本件の節を足す。
- `docs/operations/broker-execution-paths-runbook.md` のログの表 → 閉場で待つ行の意味を足す。
- `docs/operations/live-trading-cutover-runbook.md` の #12（GTC の残存）→ 閉場中は張り直さない現況を足す（「場の終了後に出し直したとき受理されるか」の問いが現況では生じない）。
- 除外: `docs/blocked-tasks.md`・`docs/operations/operations.md` #14 は実弾の挙動の未確認の記録であり、本件で事実は変わらない。

## 方式

IADR-0574 決定 1（発注執行の口 `IMarketSessionGate`・本番は共有カーネルの `MarketHours`）、決定 2（ガード: 記録済みの確定・予約の据え置きの後、張り直しの前に閉場なら `AwaitingMarketOpen` で待つ。行は Active のまま失効した逆指値を指す）、
決定 3（S1: 待ち時間・判断の手仕舞いの取消より前で閉場なら成行を送らない。到達の記録は残す。失敗に数えない）、決定 4（観測: 件数を結果へ別枠で載せ、常駐が件数の変化時だけ Information）。

## 対象外・残余

- 臨時休場・臨時の半日は足さない（発注執行に構成の口が無い）。規則計算が開場と読む臨時休場日は従来の挙動（場外で送る）に戻る。IADR-0574 残余 2。
- 東証の昼休みも閉場と読む（前場で失効した逆指値は後場の寄りで張り直す）。日本株は取引対象外。
- 開場直後の最初の巡回（最大 30 秒）までは逆指値なし。当日限りの逆指値を出している限り、従来も閉場〜翌寄りは逆指値なしだった。GTC の判断は #1214。
- 計画への環流は不要と判断した（IADR-0574 §計画との関係）。
