# ADR 索引の二重行を 1 行へ畳む

## 背景

`develop` の `.ai-context/adr/README.md` に同じ ID の索引行が 2 本ずつある（PR #951 の作業者が報告）。

| ID | 1 本目だけが持つ追記 | 2 本目だけが持つ追記 |
|---|---|---|
| IADR-0354 | ［2026-09-23 追記 / #899］ | ［2026-09-23 追記 / #889］ |
| IADR-0369 | （無し。2 本目の真部分集合） | ［2026-09-25 追記 / #938］ |

原因は、並行 PR の develop 取り込みで索引の衝突を「両側の行を並べる」機械的な和集合で解いたこと（オーケストレーター側の道具の誤り）。同じ行の両側が追記を足していると、行が 2 本になる。`check-adr-index-addendum-loss` は印の**消失**だけを見て**重複**を見ないため、素通りした。

## 是正

- IADR-0369: 2 本目（上位集合）を残し、1 本目を消す。
- IADR-0354: 共通部分 ＋ #889 の追記 ＋ #899 の追記を 1 行へ畳む。
- どちらの行も、畳む前に在った追記の印をすべて保つ（下の検証）。

## 検証

- 畳んだ後の 2 行に、畳む前の両行の印（#874・#897・#899・#889／PR #916 監査・#941・#938）がすべて在る。
- 索引行は昇順・ID の重複 0。
- `check-adr-index-addendum-loss` は「マージベースで 2 回現れた印が 1 回になった」ことを消失として報告する。これは重複の解消であり、コミット本文の `[remove-adr-addendum]` 宣言で明示する（印そのものは各 1 回残っている）。

## 射程外（別 issue）

- 索引行の ID 重複を検査器で止めること。
