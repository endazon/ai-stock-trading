# IADR-0594: 新規建ての未約定の取消（既定無効）と、未約定の新規建てがある銘柄の LLM の前の見送り

> 実装リポジトリ内の意思決定記録（Implementation ADR）。1 ファイル = 1 意思決定。

- 状態: **Accepted**
- 日付: 2026-10-29
- 決定者: Claude Code（#1486。形と既定はオーケストレーターの承認 2026-10-29。新規建ての取消の射程・値は計画の裁定待ち＝planning#852）

## 起点・関連

- 起点: #1486（PoC 2026-10-27。TSLA の新規建ての指値が一晩滞留し、同じ銘柄の判断 68 回のうち 67 回が「未約定あり」で Hold）。
- 計画: ADR-0067（判断由来の決済の指値の未約定時の取消。**射程は決済だけ**）・ADR-0072・05_trading-assumptions §5。新規建てには規則も値も無い → planning#852 を起票した。
- 前提: IADR-0539（決済の取消の実装）・IADR-0390（未約定の新規建てを判断の前提へ。決定6 は本 IADR が保有 0 について改める）・IADR-0119・IADR-0462・IADR-0463・IADR-0428。

## 決定

### 決定 1: 新規建ての取消を決済の取消と同じ本体で置き、既定は無効とする

- 取消の本体（印を先に書く・取り消すだけ・1 建玉 1 市場の現地取引日の回数・当日の注文だけ・利用者の取消と同じ口）を `UnfilledDecisionOrderCancellation` に切り出し、
  決済（`DecisionCloseUnfilledCanceller`。振る舞いは変えない）と新規建て（`DecisionEntryUnfilledCanceller`）が建玉効果を渡して呼ぶ。
- 新規建ての構成は節 `DecisionEntryUnfilledCancel`。**既定は無効**で、本番・PoC の経路の values のどちらでも有効にしない。有効時の範囲の検証は決済と同じ（N 6〜390 分・回数 1〜3）。
- 🔴 **新規建ての値は計画の裁定待ち（planning#852）であり、有効化は裁定の後とする。** 有効時の N（15 分）・回数（1 回）の初期値は、新しい値を作らず決済側の定数を共用する（暫定）。
  既定は Shared.Kernel の `DecisionEntryUnfilledCancelDefaults` に置き、リスク管理の `TradingDefaults` が公開して試験で固定する。
- 回数は新規建ての建玉（銘柄・市場・新規建ての方向）で数え、決済の取消とは別に数える（問い合わせ・数えは建玉効果を引数に取る）。
- 取り消した新規建ての保護の記録は新しい経路で閉じない。保護の巡回がエントリーの約定 0 の終端を照会で確かめ、逆指値を取り消して完了する（IADR-0428 の既存の分岐）。

### 決定 2: 保有 0 で未約定の新規建てがある銘柄は LLM を呼ぶ前に見送る

- 保有が既知で 0 で、同じ銘柄の未約定の新規建てが既知で 1 件以上なら、LLM を呼ばずに見送る（定時・価格変動とも。理由 `EntryOrderWorking`。見送りの語彙の末尾に足す）。
  この銘柄の LLM の結論は Hold・重ね買い（#934 の形）・裸の売り（IADR-0119 で必ず見送り）しか無い。
- ［PR #1490 のレビュー］**未約定の新規建ての方向を問わない。** 板に残るのが空売りの新規建てでも同じ理屈が成り立つ —— 保有 0 での売りは裸の新規売りとして
  必ず見送られ（IADR-0119。重ね売りは成立しない）、買いは板に残る空売りと反対方向の新規建てを並べることになり意味を持たない。結論は Hold と、発注にならない
  （または意味の無い）新規建てしか無い。試験は買い・空売りの両方の未約定で固定する（T-10-3078）。
- 未約定が不明・保有中（決済の判断は残す）・保有が不明では省かない。審査・発注の規則は変えない。
- 🔴 **IADR-0390 決定6「未約定が在っても新規建てはコードでは止めない」を、保有 0 について改める**（保有中の銘柄の買い増しは従来どおり止めない）。数値を伴わず、計画の統制値に触れない（費用の最適化）。

## 却下した案

- **新規建ての取消を既定で有効にする／独自の N を置く**: 計画の射程の外で統制値を作ることになる（§5 の値は方針確定プロセスか利用者の設定変更でしか変えない）。
- **決済の取消のクラスを複製する**: 取消の規律（印・回数・当日・同じ口）が 2 か所に分かれ、片方だけが直る。
- **見送りを可否の口（リスク管理）に置く**: 未約定は判断が既に読んでいる（IADR-0390）。照会を増やさず、判断の入口で決まる。

## 結果

- 未約定の新規建てが板にある間、保有 0 の銘柄の判断は LLM を呼ばない（計器: `LlmHold` の一部が `EntryOrderWorking` へ移る）。未約定が消えると次の判断から呼ぶ。
- 🔴 新規建ての取消は無効のままなので、PoC の滞留（DAY の失効まで）は裁定まで残る。それまでは利用者が証券会社の画面で取り消せる。
- 残余: 保有中の銘柄の未約定の買い増しは、LLM を呼び続ける（決済の判断のため）。
- 残余: 新規建ての取消を有効にしても、回数の上限（暫定 1 回／建玉・日）に達した後の新規建ては取り消さないので、再び DAY の失効まで滞留し得る（planning#852 の論点に含める）。
