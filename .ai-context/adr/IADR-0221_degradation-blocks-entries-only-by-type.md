# IADR-0221: 縮退は「新規建てのみ停止」を型で表し、手仕舞い・損切りを止める表現を持たせない

- 状態: Accepted
- 日付: 2026-08-28
- 決定者: claude（起票 #336。利用者レビューは PR で受ける）

## 起点・関連

- 関連する計画書 ID: FR-01 / FR-10 / NFR-04（障害時は安全側。損切りはブローカ側の逆指値が担う）/ ADR-0020 決定2・決定3
- 関連する実装仕様書: [`.ai-context/specs/20260828_336_information-collection-tiers-and-degradation.md`](../specs/20260828_336_information-collection-tiers-and-degradation.md)

## コンテキストと課題

ADR-0020 は限定縮退について「**当該機能の新規建てのみ停止。手仕舞い・損切りは継続**」と定める。
同じ規律は為替の鮮度切れでも定められており（ADR-0022 決定5）、実装では一度**破っている** ——
[IADR-0197](IADR-0197_fx-stale-exit.md) が直したのは「ゲートで一律 `return` しており、
**入口と出口が同じゲートで塞がれていた**」形である。**同型の事故を情報収集でも起こし得る。**

停止の表現をどう持つかが決定点である。`bool` フラグの集合として素直に持つと、
**フラグが増えるたびに「決済も止まる」組み合わせが生まれ得る。**

## 検討した選択肢

1. **決済側を「止められない」形にする** —— 縮退の型は新規建ての停止しか表現できず、
   `ClosesAllowed` / `StopLossAllowed` は**定数 `true`**（採用）
2. `ClosesAllowed` を可変フィールドにして、常に `true` を渡す運用にする — **渡し忘れが統制の穴になる。**
   1 箇所で `false` を渡せば出口が塞がり、**テストが無ければ気付かない。** 却下
3. 縮退を単一の enum（`None` / `EntriesBlocked` / `CycleAborted`）にする — 空売りだけを止める
   FINRA の縮退（ADR-0020 決定3）を表現できない。却下

## 決定

1. `CollectionDegradation` が持つ停止は **`AbortCycle`（新規の判断サイクルを起こさない）**・
   **`BlocksNewEntries`**・**`BlocksShortEntries`** の 3 つだけとする。
2. **`ClosesAllowed` と `StopLossAllowed` は計算プロパティで定数 `true`** とする。
   **決済を止める向きのフラグを型へ足さない。**
3. **プロパティベースのテストで全組み合わせを回し**、どの欠測の組み合わせでも決済が許可されることを固定する。
   加えて**リフレクションで「Close / StopLoss を含む bool プロパティは真である」ことを検査**し、
   将来フラグが増えて出口が塞がるようになったら赤くする。
4. **サイクル中止でも損切りは止まらない。** 実行機構はブローカー側の逆指値であり（NFR-04）、
   本サービスが止めるのは**新規の判断サイクル**だけである。ログ・監査要約にもそう書く。
5. 通知文・監査要約・KB へ書く欠測通知のいずれにも「**手仕舞い・損切りは止まっていない**」を明記する。

## 理由

- **「止められない」より「閉じられない」ほうが危険である**（IADR-0197 と同じ判断）。
  損失を抱えた建玉から出られない状態を、情報源の欠測という**補助的な事象**で作ってはならない。
- **統制は「緩む方向」だけでなく「締まりすぎる方向」にも壊れる。** 締まりすぎる壊れ方は運用中に初めて分かり、
  しかも損失として現れる。型で表現できなくするのが最も安い防止策である。
- **要約への明記は誤読対策である。** 台帳・通知を読む人が「取引が全部止まっていた」と読むと、
  事後の検証が事実とずれる（FxRateStale の要約で同じ配慮をしている）。

## 結果

- 良い影響: 縮退の判定が増えても決済経路は構造的に安全。監査・通知の文面も統一される。
- 悪い影響・トレードオフ: 「決済も止めたい」統制が将来必要になった場合、本型では表現できず
  新しい IADR と型の変更が要る。**それは意図した摩擦である。**
- フォローアップ: 縮退の `BlocksNewEntries` を**取引判断側で実際に効かせる結線**は本 PR の対象外である
  （判断サービスは収集サービスを参照しないユニット境界であり、経路は #337 の射程）。
  現時点で効いているのは**記録・通知と、判断文脈への欠測の明示**である。
