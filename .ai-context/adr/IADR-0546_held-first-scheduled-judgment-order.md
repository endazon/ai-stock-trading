# IADR-0546: 定時サイクルの判断対象で保有中の銘柄を先頭に並べる（#1367）

> 実装リポジトリ内の意思決定記録（Implementation ADR）。1 ファイル = 1 意思決定。
> 計画リポジトリの ADR（`ADR-XXXX`）とは別系統（`IADR-XXXX`）とし、実装に閉じた決定を記録する。

- 状態: **Accepted**
- 日付: 2026-10-16
- 決定者: Claude Code（実装）。#1367 の求め（保有中の銘柄を先頭に置き、上限での打ち切りでも出口判断を後回しにしない）を受け、保有の中の順序を決めた。

## 起点・関連

- 起票: [#1367](https://github.com/endazon/ai-stock-trading/issues/1367)（PoC の夜間監査 2026-10-15）
- 計画: FR-02・FR-04・UC-01・ADR-0051（利確・撤退は LLM の判断）
- 改定: **IADR-0521** 決定 1（組み立ての並び）・決定 3（打ち切りで最初に落ちるもの）。他の決定（出口専用・全注文が拒否される保有のみの除外・保有の照会の縮退）は変えない。
- 前提: IADR-0490（定時サイクルの予算と決定的な DecisionId）

## コンテキスト

定時サイクルは判断対象を直列に判断する。IADR-0521 決定 1 の並び（監視銘柄をそのままの順で先、保有のみを末尾）では、保有中の銘柄の出口判断が監視銘柄の判断の後ろに来る。
10-15 は開場直後の最初のサイクル（約 190 秒）で、平均取得単価比 −2.14%（ライン −1.5%）の AMZN の撤退判断が開始から約 3 分後（13:33:55）になった。
方針の「−1.5% 撤退」は定時の LLM 判断の経路しか無い。決定 3 は「打ち切りで最初に落ちるのは保有のみ」としており、出口を最初に捨てる並びでもあった。

## 決定

### 決定 1: 保有中の銘柄を先頭に、保有していない監視銘柄をその後ろに並べる

- `ScheduledJudgmentTargets.Build` は「保有中の銘柄（監視銘柄に在るものも含む）→ 保有していない監視銘柄（監視銘柄の順）」の並びを返す。
- 監視銘柄に在る保有銘柄は出口専用にせず（IADR-0521 決定 2 のまま）、監視銘柄の側の表記で出す（DecisionId・プロンプトの表記を変えない）。
- 監視銘柄の外の保有銘柄は出口専用（同決定 2）。全注文が必ず拒否される保有のみの銘柄は足さない（同決定 4）。保有が不明なら監視銘柄だけ（同決定 1）。
- DecisionId は起点・市場・銘柄から導くため、並びを変えても再配送の冪等（IADR-0490 決定 2）は変わらない。

### 決定 2: 保有の中の順序は保有の応答の順とする（含み損の順にしない）

- 含み損の順に並べるには巡回の前に保有ごとの現在値が要り、サイクルの頭に照会と失敗の形（不明をどちらへ倒すか）が増える。保有の供給口は銘柄だけを返す。
- 保有の数は小さく（保有建玉数の上限 3＋系の外の建玉。PoC は 4 件）、保有の塊は約 1 分で終わる。遅れの大部分は保有が監視銘柄の後ろに居たことによる。
- 急ぎの損失は S1（市場監視の損切り）が別経路で止める。応答の順は決定的で、試験で固定できる。

### 決定 3: 打ち切りで落ちるのは末尾の保有していない監視銘柄であり、警告文もそう書く

- 前提との比較（判断対象の総数）・上限・1 銘柄の締め切りは変えない（IADR-0521 決定 3・IADR-0490 決定 1）。
- 警告文は「末尾の保有していない監視銘柄から判断されなくなります（保有中の銘柄は先頭で判断する）」とする。

## 検討した選択肢

1. **保有中の銘柄を先頭（保有の応答の順）**（**採用**）— 変更は純関数 1 つ。新しい照会・失敗の形を足さない。
2. 保有中の銘柄を先頭（含み損の大きい順）— 巡回の前に現在値の照会が要る（決定 2）。保有が増えた時点で再検討する。
3. 保有のみだけを先頭、監視銘柄に在る保有は監視銘柄の位置のまま — 監視銘柄に在る保有銘柄（10-15 の AMZN の形）の出口判断が遅れたまま残る。不採用。
4. 保有の出口判断を別のメッセージに分けて並行に流す — 受信の構成・予算（consumer_timeout の制約）を引き直す大きな変更になる。不採用。

## 結果

- 開場直後の最初のサイクルで、保有中の銘柄の出口判断がサイクルの開始直後に行われる（10-15 の形では AMZN が約 3 分早まる見込み）。
- 監視銘柄の判断の開始は保有の数だけ遅れる（PoC の形で約 1 分）。
- 上限での打ち切りで判断されずに残るのは、保有していない監視銘柄（新規建ての判断）になる。

### 残余リスク

- 保有の中の順序は含み損に依らない（決定 2）。
- 急変の判断と定時サイクルの間の順序は本 IADR の対象外。
