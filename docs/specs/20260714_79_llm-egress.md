# 仕様書: 実 LLM egress（Issue #79 のうち LLM 呼び出し配線）

## 起点となる計画書（トレーサビリティ）

- 機能要求（FR）: FR-04（AI 判断）
- 関連 ADR: ADR-0003（AI 判断ガードレール）／ADR-0010（LLM ゲートウェイ・platform）
- 実装判断: [[IADR-0017]]（LLM をポートで抽象化・LLM 不在は取引しない安全既定）／[[IADR-0039]]（モデル選択はゲートウェイへ委譲）
- Issue: #79（実 LLM 費用計測と poller 配線）のうち **LLM 呼び出しの実配線**

## 目的・背景

取引判断の LLM 補完（`ILlmCompletionClient`）は `PlaceholderLlmCompletionClient`（常に Hold）で、実 LLM が
未接続だった。IADR-0017 の想定どおり **platform LLM ゲートウェイ（`POST /complete`）へ委譲する HTTP 実装**を
追加し、実 LLM 判断の経路を通す。AST は Anthropic 鍵を持たず、鍵は MSP LlmGateway 側（`llm-provider-credentials`）
にある。

> 本 PR は #79 のうち「LLM 呼び出しの実配線（egress）」に限定する。**実費用計測（LlmGateway→CostControl）**と
> **バージョン付き上限取得（#19）**はクロスユニット（#22）の後続とする。

## 対象範囲

**対象（本 PR）**
- `HttpLlmCompletionClient`: `POST {LlmGateway:BaseUrl}/complete` を呼び、応答 `Text` を返す。
  要求に `prompt/maxTokens/model/confidentiality/purpose` を載せる（ADR-0010＝platform LLM ゲートウェイの越境ルーティング判定用。本リポの FR-11＝監査ログとは別物のため ID 衝突を避け ADR で示す）。
- Program.cs 配線: `LlmGateway:BaseUrl` 未設定/不正 URI は従来プレースホルダ（fail-safe）。設定時のみ Http 実装。
  `LlmGateway:Confidentiality`（既定 internal）/`LlmGateway:Purpose`（既定 trade-decision）。

**対象外（後続）**
- 実 LLM 費用計測（LlmGateway→CostControlService の計上）・#19 バージョン付き上限取得（#22 クロスユニット）。
- デプロイ配線（chart で `LlmGateway__BaseUrl` を MSP `llmgateway-service.microservices-platform:8080` へ注入）は
  AST chart（#122）側で `--set`/values により行う。

## 設計・フェイルセーフ

- **安全既定（IADR-0017）**: 送信拒否（`Sent=false`・機密区分による縮退）／非 2xx／例外／タイムアウト／空・不正応答は
  **Hold（取引しない）**の JSON に倒す。判断パーサはこれを Hold として解釈する。
- LLM は応答が遅いため HttpClient タイムアウトは 30 秒。`ILlmCompletionClient` は他の同期照会プロバイダ
  （DailyPolicy/Sizing）と同じ scoped 解決に揃える。

## 受け入れ基準

- [x] `LlmGateway:BaseUrl` 設定時に `/complete` を呼び、応答本文を返す（fake handler テスト）
- [x] 送信拒否/非2xx/例外/タイムアウト/空・不正は Hold（取引しない）に倒す
- [x] `LlmGateway:BaseUrl` 未設定は Placeholder（実 LLM を呼ばない・fail-safe）＝選択テスト
- [ ] 実クラスタで MSP LlmGateway 経由の実 LLM 応答（要 Anthropic 鍵＝MSP 側・#22 デプロイ配線後）

## テスト方針

- 単体（fake `HttpMessageHandler`）: 成功写像／Sent=false／非2xx／例外／タイムアウト／空・不正／要求ボディ検証。
- 選択（WebApplicationFactory）: BaseUrl 有無で Http/Placeholder 切替。全 44 テスト緑。

## 計画書との差異

- 差異: なし（IADR-0017 の想定実装）。費用計測・上限取得は #22 後続として分離（#79 の残スコープ）。
