# テスト仕様書: 採算の見積り（全体前提条件の費用・最小期待利益）

> 全体前提条件の機能要求は、テスト仕様書が任意の範囲である（必須範囲は統制系の 5 つ）。
> 本書は**テスト ID の採番を docs/tests に載せるため**に起こした。試験の中身の正は xUnit テストと作業仕様書にある。
> 既にテストコードと実装の記録が使っていた番号（`T-17-01`〜`T-17-13`）を、そのまま表に載せる。

## 本書が受け持つ範囲

- 対象: 事前見積り（採算判定・バックテスト）の往復費用と、最小期待利益（不動点）の解の有無・符号。
  米国株の売りの取引諸費用（SEC 料・TAF）を事前見積りへ算入すること。採算判定の見積り不能。
  取引判断が設定サービスから読む取引諸費用の料率。
- 対象外: 事後集計（報告書の費用）の試験。リスク統制・取引ガード・段階の**既定値**の試験。

## テスト ID の帯について

`T-17-…` の帯は**本書と [リスクガードコアのテスト仕様書](./FR-10_risk-guard-core-tests.md) の 2 ファイルに跨る**。

| 範囲 | 中身 | 置き場所 |
| --- | --- | --- |
| `T-17-01`〜`T-17-13` | 採算の見積り（本書） | 本書 |
| `T-17-14`〜`T-17-17` | リスク統制・取引ガード・段階の既定値 | [リスクガードコアのテスト仕様書](./FR-10_risk-guard-core-tests.md)「既定値」 |

既定値の 4 件は、以前 `T-17-01`〜`T-17-04` の番号で載っていた。採算の境界試験も同じ番号を使っており、
**1 つの番号が 2 つの試験を指していた**。外部の参照（テストコードのコメント・作業仕様書・実装の記録）は
すべて採算の境界試験の側を指し、既定値の側を指す参照は 1 件も無かった。そこで既定値の側を
`T-17-14`〜`T-17-17` へ移した。旧番号の `T-17-01`〜`T-17-04` は、本書の採算の境界試験だけを指す。

## テスト観点

境界値（`倍率 × 税率 = 1` の直前・ちょうど・直後）／プロパティベース（どの入力でも負のしきい値を返さない）／
否定形（米国株の売り以外に諸費用を掛けない・登録費用 0 で判定を緩めない・欄の無い応答を 0 で埋めない）。
