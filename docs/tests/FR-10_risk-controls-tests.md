## 3 点セット（テスト戦略 §2）

統制系のテストは**境界値テーブル・プロパティベース・否定形**の 3 種を必ず揃える。
閾値はマジックナンバーで書かず統制設定から引き、設定値の正しさは計画適合検査が別途担保する。

### 為替レートの鮮度による縮退（#381。為替レート源の計画 ADR の決定 4・5）

## 維持率の適用閾値は口座単位（#420。空売り段階解禁の計画 ADR の決定 7 の 2026-08-07 追記）

> **本群が塞ぐのは「同じ規則を 2 か所に書いた」ことによる食い違いである。** 自動縮小は
