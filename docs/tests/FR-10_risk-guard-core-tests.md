# テスト仕様書: リスクガードコア（FR-10/12/19/20）

> 計画書の受け入れ基準と作業仕様書のチェックリストを、実装済みの xUnit テストへ写像した対応表。
> 対象は `RiskManagementService.Domain.Tests`（RiskEvaluator / PositionSizer / TradingDefaults）と
> `AiStockTrading.Shared.Infrastructure.Tests`（PaperBrokerAdapter）。
>
> **テスト件数の注記**: リスク評価コア是正（Issue #25〜#31）・サイジングキャップ（#29）・トレーサビリティ整備（#32）は
> develop にマージ済み。develop 現状は 58 件（ドメイン 54 / インフラ 4）で、相場操縦・段階資金上限・日次損失合算・
> サイジングキャップ等を含む。本 PR は証券会社拒否（#30・`OrderStatus.Rejected`）を統合しており、統合後は
> 63 件（ドメイン 54 / インフラ 9）。#30 の統合が develop に載れば develop も 63 件になる。件数は Issue 単位で示す
> （PR 番号帰属はスカッシュマージのため git 履歴単独では追えないため）。テストメソッド名は日本語識別子で、各テストの
> コメントに起点 ID を残している。

## 起点となる計画書（トレーサビリティ）

- 機能要求（FR）: FR-10（リスク統制）、FR-12（ペーパートレード）、FR-19（取引ガード）、FR-20（段階ゲート）
- ユースケース（UC）: UC-01/UC-02（取引サイクルの検証段）、UC-06（設定変更・緊急停止）
- 受け入れ基準の所在: `02_requirements/01_requirements.md`、`05_trading-assumptions.md` §5、作業仕様書
  `docs/specs/20260708_risk-guard-core.md` / `docs/specs/20260709_risk-eval-core-fixes.md`

## テスト対象・範囲

- 対象: 発注前の決定的判定（`RiskEvaluator.Evaluate`）、ポジションサイジング（`PositionSizer`）、既定値
  （`TradingDefaults`）、ペーパーブローカー（`PaperBrokerAdapter`）の単体テスト。
- 対象外（別スライス）: サービスホスト・MassTransit 配線・PostgreSQL 永続化、サイジング→発注意図→検証の結合
  テスト（取引判断サービス。IADR-0003）、相場操縦検知アルゴリズム本体（後続スライス。IADR-0006）、
  ロックアウト状態管理（リスク管理ホスト #12）。

## テスト観点

- 正常系（制約を満たす注文の承認）、異常系（各違反理由の拒否）、境界値（上限ちょうど/上限+1）、
  フェイルセーフ（手仕舞い Close はエントリー制約の対象外）、全違反列挙（監査性 FR-11）。

- 既定設定は `TradingDefaults.CreateSettings()`。個別ケースは `PortfolioSnapshot` / `OrderIntent` のヘルパ
  （`Snapshot(...)` / `Buy(...)` / `Close(...)` / `ShortEntry(...)`）で境界値を注入する。

## 未カバー・実施予定

| 項目 | 理由 | 実施予定スライス |
| --- | --- | --- |
| サイジング→発注意図→`RiskEvaluator` 検証の結合 | 呼び出し側（取引判断サービス）責務（IADR-0003） | 取引判断サービス（#11） |
| 相場操縦検知アルゴリズム本体 | 注文履歴統計・閾値は運用データ待ち（IADR-0006） | 発注執行後続スライス |
| ロックアウト（翌営業日まで）状態管理 | `RiskEvaluator` はステートレス（IADR-0008） | リスク管理ホスト（#12） |
| 連敗縮小の実運用連動（勝ちトレードでの復帰） | 状態管理が必要 | リスク管理ホスト（#12） |
